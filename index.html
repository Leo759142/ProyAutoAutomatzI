📝 Propiedades del Nodo

🎯 GUÍA COMPLETA - Editor de Nodos

🚀 INICIO RÁPIDO:

  1. Carga un Template: Dropdown "📁 Seleccionar Template" → "🚀 TUTORIAL" → "Cargar"
  2. Presiona ▶ Play: Los nodos se ejecutan inmediatamente
  3. Observa: Los valores aparecen bajo cada nodo

1️⃣ CREAR Y EDITAR NODOS:

  • Crear: Botón "Add Node (+)" o tecla A
  • ✏️ EDITAR VALORES: Doble-click en el nodo 👈 ¡IMPORTANTE!
  • Aplicar cambios: Edita valores en panel derecho → "✔ Aplicar"
  • Mover: Arrastra desde el centro del nodo
  • Seleccionar: Click simple (Ctrl+Click para múltiple)
💡 Para cambiar el valor de un nodo Number de 0 a 50: Doble-click → Cambiar valor → Aplicar

2️⃣ CONECTAR NODOS:

  • Paso 1: Click en pin de SALIDA (círculo derecho)
  • Paso 2: Arrastra hasta pin de ENTRADA (círculo izquierdo)
  • Línea amarilla: Indica conexión exitosa
  • Eliminar: Click derecho en conexión
⚠️ Solo se conectan tipos compatibles (Number→Number, Boolean→Boolean)

3️⃣ ▶️ EJECUTAR FLUJO:

  • ▶ Play: Inicia la ejecución continua
  • ⬛ Stop: Detiene completamente
  • Modo Tiempo Real: Ejecuta cada 100ms (rápido)
  • Modo Paso a Paso: Ejecuta cada 1s (ver proceso)
🎯 Los resultados aparecen bajo cada nodo en tiempo real

⌨️ ATAJOS DE TECLADO:

AAgregar nodo en posición del cursor
DeleteEliminar nodos seleccionados
Ctrl+GCentrar vista en origen (0,0)
RuedaZoom in/out (desde centro)
Click medioArrastrar canvas (pan)
Shift+DragSelección múltiple

🔧 CREAR NODOS PERSONALIZADOS:

Edita el archivo src/core/NodeTypes.ts:

"mi_nodo": {
  type: "mi_nodo",
  category: "custom",
  title: "Mi Nodo",
  inputs: [
    { name: "input", type: PinType.Number }
  ],
  outputs: [
    { name: "result", type: PinType.Number }
  ],
  compute: (inputs) => [inputs[0] * 2]
}
📝 Reinicia la app después de agregar nuevos nodos

💾 GUARDAR/CARGAR:

  • Templates: Workflows completos con múltiples nodos
  • Auto-guardado: Los templates se guardan en navegador
  • Cargar: Dropdown + botón "Cargar Template"

📚 Más info: Revisa archivos .md en la raíz del proyecto

🐛 Problemas? Verifica la consola del navegador (F12)
